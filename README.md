# kirbo-koomba
kirby desk vaccum thing
# Features
navigation patterns
- wall following
- random bouncing off objects to change direction
- adapts better with more use

newer ver have vslam that takes snapshot of room

infrared (motion) & photocell (light level) sensors 
- ideas for proj: ir cliff sensor, ultrasonic, limit switch
- infrared at the front; bounces light off objects to detect distance from them
- sees how long infrared beam takes to bounce off object and to the photocell sensor

wheels
- optical encoders that use light sensors to determine how far robot’s traveled
- similar to odom but w light blocking and stuff

two multilayer brushes
- one pulls in debris
- the other accelerates dust and stuff towards the vacuum

ion batteries

sensors in brushes to prevent entanglement

piezoelectric sensor for especially dirty spots

motors for brush, fan, and wheels
